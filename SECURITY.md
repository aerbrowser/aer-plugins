# Security and privacy

Do not commit API keys, signing private keys, account cookies or real user drafts. The catalog contains only a public verification key and public release metadata.

Only user-triggered page reads and AI transformations are supported. Plugins cannot publish posts or operate account forms. Review extracted text and model output before using it.

Host API 3 is a development preview until the AER host has been compiled and exercised. Report issues to the repository maintainers without posting credentials or personal page data in public issues.
