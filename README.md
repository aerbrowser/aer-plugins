# Aer Plugins

AER 的四个开源浮动运营助手，来源于 X 知识助手的页面提取与内容创作流程。插件由 GitHub 独立分发，不依赖 Chrome 扩展商店。

> **当前源码为 0.2.0 / Host API 4，尚未发布。** 新增打开自动读取、标题/正文编辑和平台自动填入。公开签名目录仍是 0.1.0 / API 3。需先发布兼容的新 Aer，再发布四个插件包；不要把此源码状态当作安装版已有功能。真实平台与模型流程仍待验收。

| 插件 | 主要用途 |
| --- | --- |
| 公众号助手 | 文章整理、忠实翻译、公众号二创 |
| 小红书助手 | 笔记改写、标题与标签 |
| X 助手 | 帖子与长文翻译、缩写、串文 |
| 头条号助手 | 资讯整理、文章改写与标题 |

四个插件均支持读取当前页或选中文字、粘贴素材、翻译、二创、缩写、拟标题、编辑结果、复制与本地草稿。模型服务使用 AER 中已有的 API 配置，密钥不进入插件。发起内容处理前，界面明确提示素材将发送到用户配置的模型服务。

## 使用方式（0.2.0 需要支持 API 4 的 Aer）

1. 打开 **设置 → Aer 插件**，下载需要的助手。
2. 网页右侧默认显示可拖动的 Aer Logo；未安装也能从入口前往安装。
3. 打开助手后自动读取当前页素材；已有草稿优先保留，当前页有新内容时提示重新读取。
4. 翻译、二创、缩写仍需点击。标题与正文分开编辑，拟标题提供备选项，不覆盖正文。
5. 点击「填入平台编辑器」，在新标签完成登录。公众号、头条号填入标题和正文，X 填入一条帖子，小红书待用户选择类型、上传图片后继续。
6. 核对内容、图片、封面与必填项，在平台确认发布。助手不会点击发布或提交按钮。

### 视频工作流

在任一插件的「视频」页，页面中的可下载 MP4/WebM/MOV 会显示尺寸、时长和清晰度，可保存到 Aer 下载目录；HLS/DASH 分段流、blob 临时视频和加密媒体会明确标记为不能直接下载。也可以把原文或创作稿拆成分镜，编辑字幕、图片和时长后导出 1080×1920 MP4。

「发布视频」支持视频号和小红书视频：插件先保存或使用刚导出的本地视频，再打开固定平台发布页并填入标题/正文。视频文件由你在平台手动上传，封面和最终发表由你确认；当前版本没有自动上传或自动发布。

面板默认宽 420 点，跟随网页可用高度，可调整宽度。关闭/收起面板返回原位置的 Aer Logo；草稿保留。编辑器导入使用专属任务，等待登录时可返回来源助手查看状态或停止任务，最长等待 10 分钟。已有平台稿件不会被覆盖；无法确认完整填入时提示手动检查。

关闭方式：

- **本次关闭**：当前文档不再显示，导航到新文档后恢复。
- **此网站不显示浮窗**：写入当前浏览器资料的网站排除规则，包含子域名。
- **全局关闭浮窗**：持久保存，需从设置重新开启。
- 设置还提供每个插件的显示开关与独立网站排除列表。

## 仓库结构

- `plugins/*/manifest.json`：四个独立插件的身份、平台写作指令和权限。
- `shared/`：共享浮窗 UI 和处理交互。
- `sdk/aer.js`：受限的宿主桥接客户端。
- `scripts/package.py`：确定性的纯源码 ZIP 打包，无构建依赖。
- `scripts/catalog.mjs`：签署分发目录，私钥必须放在仓库外。
- `catalog/stable.json`：签名版本目录；`trust.json` 仅含公钥。
- `docs/host-api.md`：宿主协议与边界。

## 发布

```sh
python3 scripts/package.py
AER_PLUGINS_SIGNING_KEY=/secure/path/private.pem node scripts/catalog.mjs
```

四个 `.aerplugin` 上传至同一版本的 GitHub Release（例如 `v0.1.0`），确认资产可用后发布 `catalog/stable.json`。包不可原地覆盖：内容变化必须提高版本。目录有效期为 180 天，维护者需要在过期前重新签署并发布；客户端不会自动接受新公钥，换钥需要宿主显式更新信任。目录采用 AER 已有签名容器格式，负载的 `apps` 字段仅用于复用验证协议。

源码包默认不含宿主。AER 宿主负责签名校验、动态下载、安全解包、原生浮窗、网站规则、页面采集、AI 调用和按浏览器资料隔离的数据存储。插件不得启动进程、访问文件系统、读取 Cookie 或执行任意页面脚本。

## 迁移范围

迁移 X 知识助手的选区优先提取思路、X 长文选择器、视频候选识别、清晰度元数据和翻译与术语偏好，重组为四个平台的独立文本与视频工作流。0.2.0 增加固定平台编辑器适配，保留作者在平台确认上传和发布。没有迁移原扩展保存的 API Key、账号或私人草稿，也不自动注入跨扩展的远程文件上传链路。
