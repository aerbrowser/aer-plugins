# AER Plugins

AER 的四个开源浮动运营助手，来源于 X 知识助手的页面提取与内容创作流程。插件由 GitHub 独立分发，不依赖 Chrome 扩展商店。

> **当前为 0.1.0 开发预览。** 下载包要求 AER Floating Plugin Host API 3。宿主接入源码已在 AER 本地开发分支中添加，但尚未编译或完成真实浏览器验收；现有正式版 AER 不能直接使用这些包。`.aerplugin` 不是 Chrome CRX 扩展。

| 插件 | 主要用途 |
| --- | --- |
| 公众号助手 | 文章整理、忠实翻译、公众号二创 |
| 小红书助手 | 笔记改写、标题与标签 |
| X 助手 | 帖子与长文翻译、缩写、串文 |
| 头条号助手 | 资讯整理、文章改写与标题 |

四个插件均支持读取当前页或选中文字、粘贴素材、翻译、二创、缩写、拟标题、编辑结果、复制与本地草稿。模型服务使用 AER 中已有的 API 配置，密钥不进入插件。发起内容处理前，界面明确提示素材将发送到用户配置的模型服务。

## 使用方式（需要支持 API 3 的 AER）

1. 打开 **设置 → AER 插件**，下载需要的助手。
2. 安装后浮窗默认显示。同一标签页只显示一个助手；优先选择当前网站对应的已安装助手，也可从浮窗菜单切换。
3. 点击“读取页面”，或粘贴素材，再选择处理动作。插件不会在安装、打开或导航时自动读取正文或发送模型请求。
4. 可以拖动原生标题栏、调整窗口大小，或收起为小窗。切换标签页隐藏旧浮窗，返回后继续原有内容。

关闭方式：

- **本次关闭**：当前文档不再显示，导航到新文档后恢复。
- **此网站不显示浮窗**：写入当前浏览器资料的网站排除规则，包含子域名。
- **全局关闭浮窗**：持久保存，需从设置重新开启。
- 设置还提供每个插件的显示开关与独立网站排除列表。

## 仓库结构

- `plugins/*/manifest.json`：四个独立插件的身份、平台写作指令和权限。
- `shared/`：共享浮窗 UI 和处理交互。
- `sdk/aer.js`：受限的宿主桥接客户端。
- `scripts/package.py`：确定性的纯源码 ZIP 打包，无构建依赖。
- `scripts/catalog.mjs`：签署分发目录，私钥必须放在仓库外。
- `catalog/stable.json`：签名版本目录；`trust.json` 仅含公钥。
- `docs/host-api.md`：宿主协议与边界。

## 发布

```sh
python3 scripts/package.py
AER_PLUGINS_SIGNING_KEY=/secure/path/private.pem node scripts/catalog.mjs
```

四个 `.aerplugin` 上传至同一版本的 GitHub Release（例如 `v0.1.0`），确认资产可用后发布 `catalog/stable.json`。包不可原地覆盖：内容变化必须提高版本。目录有效期为 180 天，维护者需要在过期前重新签署并发布；客户端不会自动接受新公钥，换钥需要宿主显式更新信任。目录采用 AER 已有签名容器格式，负载的 `apps` 字段仅用于复用验证协议。

源码包默认不含宿主。AER 宿主负责签名校验、动态下载、安全解包、原生浮窗、网站规则、页面采集、AI 调用和按浏览器资料隔离的数据存储。插件不得启动进程、访问文件系统、读取 Cookie 或执行任意页面脚本。

## 迁移范围

这一版迁移 X 知识助手的选区优先提取思路、X 长文选择器、翻译与术语偏好，重组为四个平台的独立文本工作流。原有视频下载、图片生成、Obsidian 导出、编辑器自动填入与账号发布不属于本次迁移范围；没有迁移原扩展保存的 API Key、账号或私人草稿。
